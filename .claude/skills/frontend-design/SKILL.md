# Дизайн экранов JobToo

Этот скилл — навигатор. Подробности лежат в отдельных скиллах, здесь — что брать
и что в проекте уже решено.

## Куда идти за чем

| Задача | Скилл |
|---|---|
| Иерархия на экране, что главное | `visual-hierarchy` |
| Размеры и ритм текста | `typography-scale` |
| Цвета, токены, тёмная тема | `color-system`, `design-token`, `theming-system` |
| Отступы | `spacing-system` |
| Формы и ввод | `form-design` |
| Пустые состояния и загрузка | `loading-states`, `error-handling-ux` |
| Навигация | `navigation-patterns` |
| Движение | `motion-system`, `animation-principles` |
| Разные экраны | `responsive-design` |
| Проверка чужого макета | `design-critique`, `heuristic-evaluation` |
| Первый запуск | `onboarding-design` |
| Доступность | `accessibility-audit` |

## Что в JobToo уже решено — не переизобретать

**Карточка ленты.** Внутри прокрутки нет. Показывает то, по чему принимают решение:
логотип, компания, «40 минут назад», название, чипы, обрезанное описание, ссылка
«Читать полностью». Всё остальное — на экране подробностей.

**Чипы.** Один размер, спокойный серый, в одну строку. Цветом выделяется только
зарплата — то, ради чего карточку открывают. Адрес — такой же чип, а не толстая плашка.

**Экран вакансии** один для смен, постоянных вакансий и партнёрских. Общие куски:
`VacancyDetailHead` (шапка), `VacancyContacts` (контакты), `CompanyMark` (знак компании).

**Контакты скрыты до входа.** Не размытием — полосками: размытый текст на части
устройств остаётся читаемым, и это была бы видимость защиты.

## Правило

Прежде чем рисовать новый элемент — проверить, нет ли уже такого в `components/ui`.
Второй похожий компонент расходится с первым через месяц.
