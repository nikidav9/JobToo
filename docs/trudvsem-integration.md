# Работа в России (trudvsem)

Источник импортирует только вакансии Москвы через официальный open-data API.

- Все вакансии источника имеют `kind=permanent` и показываются в разделе «Работа».
- В «Подработка → Регулярная» дополнительно попадают только вакансии с признаками повторяющейся занятости (сменный/гибкий график, частичная занятость и т. п.).
- Arbihunter в «Регулярную» не попадает и остаётся только в разделе «Работа».
- Отклик на внешнюю вакансию ведёт на оригинальную страницу источника.
