## 1. Что построено и работает

### Рост / активация
- **Гостевой режим** — вход в ленту без регистрации (соискатель). Любое
  действие ведёт на регистрацию, в базу от имени гостя ничего не пишется.
- **Событие «открыл приложение»** (`jm_app_opens`) — воронка установил → открыл
  → зарегистрировался, роль (соискатель/работодатель) в момент открытия.
- **Гостевая воронка кампаний** — события `guest_started`, `vacancy_impression`,
  `campaign_apply`, `campaign_open`, `campaign_shared`, `external_click`,
  `registration_started/completed`. Инструментирована в приложении end-to-end.
- **Дашборд владельца** (`dashboard/`) — отдельные страницы: воронка (`funnel`),
  источники (`sources`), метчинг, партнёрский отчёт.

### Деньги / партнёры
- **Импорт фида** (`php-proxy/ingest.php`) — нормализация (метро, тип работы,
  ставка, даты), дедуп, фильтр дискриминационных объявлений, безопасная
  загрузка с лимитом размера и пагинацией. Готов принять фид «Яндекс Смены»
  (формат — `docs/feed-format.md`, обязательны `id`, `title`, `url`).
- **Партнёрский шлюз заявок** (`php-proxy/partner_core.php`) — конечный автомат
  статусов смены (создана → отправлена → принята → бронь → чек-ин → завершена,
  с ветками отмен/споров/неявки), проверка подписи вебхуков, ретраи,
  оптимистичная конкуренция по версии события.
- **Биллинг и сверка** (`php-proxy/partner_billing.php`) — тарифы по источнику и
  типу события, дедуп начислений, сверка «наше ↔ партнёр», помесячные строки,
  выгрузка в CSV.
- **Изолированная песочница** партнёра и защита ключей источников.
- **Telegram** (`php-proxy/tg.php`) — бот с диплинками в конкретную вакансию,
  атрибуция кампаний, персональные настройки уведомлений (`/settings`).

## 2. Приёмка (чем проверено)
- PHP-синтаксис всех файлов прокси — чисто.
- Миграции — 3 повтора номеров (014, 033, 043) на **разных** таблицах;
  `migrate.sh` учитывает по имени файла, каждая применяется один раз, данные не
  теряются. Косметика, не поломка. **Не трогаем** — переименование уже
  применённых миграций заставит накатить их заново.
- Тесты партнёрского ядра и песочницы на месте.
- Не проверено локально: живой прогон в приложении (сборка проходит, ручного
  клика нет) и статус CI (коннектор статусов сборок недоступен).

## 3. Что осталось — по линиям

### Деньги (до первого живого партнёра)
1. Получить реальный адрес фида «Яндекс Смены» (или другого партнёра) и
   завести источник — код импорта уже готов.
2. Прогнать один источник через песочницу до прода, проверить сверку и отчёт.
3. Подготовить демонстрацию партнёрского отчёта (аудитория, регионы, CPA) для
   разговора с крупной компанией.

### Рост (что даст данные и конверсию)
1. Дать событиям накопиться 2–3 дня (гостевая воронка + активация).
2. Найти самый слабый шаг воронки (открыл → отклик → регистрация → первая
   смена) и усилить именно его.
3. Ре-энгейджмент спящих (ядро уже есть — безопасная Telegram-реактивация).
